Why another JSON viewer?

In April 2026, the 3-million-user JSON Formatter Chrome extension was sold and turned into adware — injecting tracking scripts and hijacking checkout pages.

Every closed-source viewer carries the same risk: you can't audit what it does with your API responses, JWTs, and customer data.

PrivJSON is different by construction:

Zero network requests after load — verify it in DevTools › Network.

Single HTML file — save it and run it offline forever.

Readable source — ~600 lines, no build step, no dependencies.

⚡ 100MB+ without freezing

Chunked async parsing keeps the UI responsive. Virtualized-ish collapsed rendering won't choke on 1M-node arrays.

🔒 Private by architecture

Not "we respect your privacy" — there is literally no upload path. Parse happens in your tab's memory. Close the tab, data is gone.

🧰 Tools you actually use

Collapsible tree, instant key/value search, JSONPath-style copy, array-as-table view, big-number & BigInt safe.
